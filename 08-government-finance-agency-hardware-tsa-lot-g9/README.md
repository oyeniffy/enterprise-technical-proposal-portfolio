#### 1.0 EXECUTIVE SUMMARY

Task Systems Limited hereby submits this comprehensive technical proposal for the G9 Purchase
of Computers & Computer Consumables for TSA Operations. Our understanding of TSA’s
operational environment emphasizes the need for secure, high-performance, and reliable
computing infrastructure capable of supporting daily transaction processing, data management,
document handling, and mission-critical administrative functions. This proposal addresses the full
lifecycle requirement from procurement of OEM-certified equipment to delivery, installation,
configuration, testing, and final commissioning ensuring strict compliance with the Schedule of
Requirements and all specified technical standards.

Our solution prioritizes performance, scalability, durability, and operational continuity. All
equipment proposed is manufacturer-backed, covered by standard OEM warranties, and
supported by a structured post-installation support framework to minimize downtime and ensure
long-term sustainability. We are committed to delivering within the stipulated project timeline
while maintaining quality assurance controls, proper documentation, and technical handover
procedures. Through this engagement, Task Systems Limited guarantees a reliable ICT foundation
that enhances TSA’s operational efficiency, security posture, and overall service delivery
capability.

#### 4.0 INSTALLATION METHODOLOGY

Our installation approach is designed to ensure minimal disruption to ongoing TSA operations
while guaranteeing that all equipment is professionally deployed, fully configured, and rigorously
tested before handover. The methodology follows a phased approach encompassing pre-
installation planning, physical installation, configuration, and acceptance testing.

#### 4.1 Pre-Installation Preparation

Successful installation begins with thorough preparation. Prior to mobilizing to site, our project
team will undertake the following preparatory activities:

### 1. Site Assessment: Our technical team will conduct a comprehensive site assessment at

       Treasury House, Abuja, to verify environmental readiness. This includes confirming
       adequate power supply availability at each designated workstation, assessing network
       connectivity points, and ensuring proper ventilation and physical space for all equipment.

### 2. Coordination with [Client] ICT Department: As explicitly required in the Schedule of

       Requirements, we will closely coordinate with the [Client] ICT Department before receiving
       and installing any equipment. This coordination will include:

      Agreeing on the installation schedule to avoid peak operational periods

      Confirming network configuration requirements, including IP address allocation, domain
       integration, and security policies

      Discussing any specific software applications to be pre-loaded on the systems

### 3. Data Backup and Migration Planning: Where migration of existing user data is required,

       we will work with the ICT department to ensure comprehensive backups are performed
       before any new system deployment. A clear data migration protocol will be established to
       prevent data loss and ensure a smooth transition for end users.

### 4. Equipment Pre-Delivery Verification: Before transportation to site, all equipment will

       undergo internal quality assurance checks to verify functionality, confirm correct

#### 4.2 Desktop Installation Process

The desktop computer installation will be executed systematically to ensure each workstation is
fully operational and ready for user handover.

### 1. Physical Setup: Each desktop unit will be carefully unpacked and positioned at the

       designated workstation as directed by the [Client] ICT team. Monitors will be placed at
       ergonomic heights, and all cables will be neatly organized to maintain a professional and
       safe workspace environment.

### 2. Power Integration: Each desktop will be connected to power through the supplied UPS

       units, ensuring comprehensive power protection. The UPS will be properly configured,
       and users will be briefed on its correct operation and the importance of connecting only
       protected equipment.

### 3. Network Connectivity: Systems will be connected to the [Client] network as specified—

       either via wired Ethernet connection for optimal performance or Wi-Fi where required.
       Network settings will be configured according to [Client] ICT specifications, including static
       or dynamic IP assignment as directed.

### 4. Operating System Configuration: All desktop computers will be delivered with genuine

       Windows 11 Pro licenses pre-installed. Our engineers will perform initial system
       configuration, including:

      Activating the Windows license

      Applying the latest Windows updates and security patches

      Configuring user account settings

      Setting up power management profiles

      Ensuring all system drivers are properly installed and functioning

### 5. Software Installation: Working from a list provided by the [Client] ICT department, our team

       will install all authorized software applications required for TSA operations. This may

       approved tools.

### 6. User Profile Creation and Data Migration: For replacement scenarios, user profiles will be

       created on the new systems, and data will be migrated from existing machines following
       the agreed backup and migration protocol. Users will be involved in verifying that all
       critical data has been successfully transferred.

#### 4.3 Printer Installation Process

The printer installation will be executed to ensure seamless integration into the [Client] network
environment and immediate usability for all authorized staff.

### 1. Physical Placement: Printers will be positioned in the designated locations as specified by

       the [Client] ICT department. Placement will consider factors such as:

      Accessibility for all users

      Proximity to power outlets and network points

      Adequate ventilation and space for paper loading and output tray clearance

      Security considerations for sensitive printing areas

### 2. Network Configuration: Each printer will be assigned a static IP address as per [Client]

       network policy. Network settings will be configured to ensure the printer is discoverable
       on the network and accessible to all authorized workstations.

### 3. Driver Installation: Printer drivers will be installed on all relevant workstations, either

       individually or through network deployment tools. Driver versions will be verified for
       compatibility with the Windows 11 Pro operating environment.

### 4. Print Queue Setup: Print queues will be created and configured on print servers or

       workstations as appropriate. Default printer settings will be established, and printer
       sharing permissions will be configured according to [Client] requirements.

### 5. Testing and Verification: Comprehensive testing will be conducted to verify:

      Print functionality from multiple workstations
