### 1. Executive Summary

The [Confidential Client — National Judicial Institution] ([Client]) plays a vital role in ensuring the effective administration and
governance of the judiciary across Nigeria. As the judicial system continues to modernize its
operations and adopt digital technologies, the need for a secure, scalable, and well-governed
cloud environment becomes increasingly important. A modern technology platform will enable
[Client] to enhance collaboration, improve operational efficiency, strengthen data security, and
ensure reliable access to critical information across its offices and stakeholders.

Task Systems Limited proposes to partner with the [Confidential Client — National Judicial Institution] in the design,
deployment, licensing, and continuous optimization of a secure Microsoft Azure and Microsoft
365 enterprise environment under a three-year strategic engagement. Through this partnership,
Task Systems Limited will provide cloud infrastructure deployment, Microsoft 365 service
enablement, Microsoft licensing management under the Licensing Solution Provider (LSP)
framework, annual technology assessments, structured training programs, and ongoing technical
advisory services. This approach will ensure [Client] benefits from a secure cloud platform, optimized
licensing investments, improved collaboration tools, and continuous technical capability
development while maintaining strong governance across its technology ecosystem.

### 3. Proposed Solution Overview

Task Systems Limited proposes a comprehensive technology solution built on Microsoft’s
enterprise cloud platform, integrating Microsoft Azure cloud infrastructure, Microsoft 365
productivity services, and structured licensing management under the Microsoft Licensing
Solution Provider (LSP) program. This integrated approach will provide the [Confidential Client — National Judicial Institution] ([Client]) with a secure, scalable, and well-governed technology environment that supports
operational efficiency, collaboration, and long-term digital transformation.

The proposed solution is structured across three key pillars:

   a) Cloud Infrastructure (Microsoft Azure)

Task Systems Limited will create and deploy a secure and scalable Azure cloud
environment/tenant to support [Client]’s infrastructure and application requirements. The Azure
platform will enable reliable application hosting, secure data storage, identity and access
management, disaster recovery and backup capabilities, and a secure networking architecture.

Key benefits of the Azure environment include:

      High availability and reliability of infrastructure services

      Enterprise-grade security and compliance capabilities

      Elastic scalability to accommodate future growth

      Advanced monitoring, governance, and cost optimization tools

### 5. Implementation Approach

Task Systems Limited will adopt a structured and phased implementation methodology to ensure
the successful deployment, secure configuration, and long-term sustainability of the [Confidential Client — National Judicial Institution]’s Microsoft Azure and Microsoft 365 environment. This approach ensures
minimal disruption to existing operations while enabling [Client] to fully realize the benefits of the
proposed cloud and productivity platform. The implementation will be executed across four key
phases:

     Phase 1: Environment Setup

The first phase focuses on establishing the foundational cloud environment, including contractual
agreements, and configuring the core platform components required for secure operations.

Key activities in this phase will include:

       Configuration of the Microsoft Azure tenant environment

       Setup of the Microsoft 365 tenant and foundational services

       Implementation of identity and access management controls

       Establishment of baseline security configurations aligned with Microsoft best practices

This phase ensures that the core cloud infrastructure is properly established and secured before
service deployment begins.

     Phase 2: Service Deployment
